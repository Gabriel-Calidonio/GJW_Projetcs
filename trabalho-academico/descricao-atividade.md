# Nesta entrega final, o grupo deverá apresentar o Projeto Integrador completo, reunindo a 1ª fase: Back-end/API e a 2ª fase: Front-end.

A aplicação deverá possuir uma interface web funcional, desenvolvida com framework front-end, integrada ao back-end em Java e Spring Boot. O sistema deve utilizar banco de dados relacional, API REST, operações CRUD e, quando aplicável, autenticação de usuários.

## Requisitos da aplicação
A entrega deverá demonstrar:

* Back-end desenvolvido com Java, Spring Boot e banco de dados relacional;
* Arquitetura organizada em Controller, Service, Repository e Model/Entity;
* API REST com operações de cadastro, listagem, consulta por identificador, atualização e exclusão;
* Uso adequado de GET, POST, PUT/PATCH e DELETE;
* Validações, tratamento de erros e códigos HTTP adequados;
* Cadastro e login de usuários, segurança e proteção de endpoints, quando aplicável;
* Front-end desenvolvido com Angular, React, Vue ou tecnologia equivalente aprovada;
* Interface responsiva e organizada;
* Formulários com validação e mensagens de sucesso ou erro;
* Integração real entre front-end, API e banco de dados;
* Uso de Git/GitHub, com participação identificável de todos os integrantes;
* Front-end e back-end publicados e funcionando.


## A 1ª e a 2ª fases serão apresentadas juntas no dia 17 e 24 de novembro.

Cada grupo terá até 15 minutos para demonstrar a aplicação completa. Todos os integrantes devem estar presentes, participar da apresentação e ser capazes de explicar sua contribuição e as decisões técnicas tomadas.

## Durante a apresentação, o grupo deverá demonstrar:

* Contexto e objetivo do projeto;
* Organização do back-end e banco de dados;
* Funcionamento da API REST;
* Interface desenvolvida;
* Operações de CRUD pela interface;
* Integração entre front-end, back-end e banco de dados;
* Autenticação, quando utilizada;
* Aplicação publicada e funcionando.
