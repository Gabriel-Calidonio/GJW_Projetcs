# Introdução

Atualmente, a Tgo's Barbearia enfrenta dificuldades relacionadas à organização do atendimento e à sua presença digital. Muitos clientes ainda dependem de contato direto via WhatsApp ou atendimento presencial para obter informações ou agendar serviços, o que pode gerar demora nas respostas, conflitos de horários e perda de oportunidades de atendimento. Além disso, a ausência de um website profissional limita a visibilidade da barbearia no ambiente online, dificultando a atração de novos clientes e a consolidação da marca no mercado, especialmente considerando que grande parte dos consumidores busca serviços pela internet antes de tomar uma decisão. Por isso nossa solução é criar um website para a Tgo’s Barbearia de modo que atenda as características especificas do negócio, por exemplo o cliente pode acessar o site e verificar os horários disponíveis, tipos de cortes, realizar agendamento, escolher dia e hora disponível.

# Metodologia

O projeto adotou a metodologia ágil Scrum em ciclos incrementais, iniciando pelo levantamento de requisitos junto à barbearia, elaboração de User Stories e cenários BDD (Gherkin), seguidos de modelagem de banco (diagrama EER), diagramas UML de classes e sequência, topologia de rede e prototipação das telas. No back-end, aplicou-se arquitetura em camadas (Controller, Service, Repository e Entity/DTO) associada a padrões de projeto como DAO (DataMapper e QueryBuilder via JDBC puro com PreparedStatement contra SQL Injection), DTO, Factory e Unit of Work transacional, permitindo compatibilidade com MariaDB/MySQL ou PostgreSQL configurável pelo instalador web (/setup). No front-end, utilizaram-se HTML5 semântico, CSS3 responsivo, Thymeleaf e JavaScript modularizado por responsabilidade para interações assíncronas no DOM sem recarregamento. A qualidade foi mantida com versionamento colaborativo em Git/GitHub, padronização e análise estática (Spotless e SpotBugs), testes automatizados com JUnit 5, MockMvc, ArchUnit e Playwright E2E, além de deploy em VPS Debian via Fat JAR gerenciado pelo Systemd sob proxy reverso Nginx em HTTPS.

# Desenvolvimento

O sistema web do Tgo's Barbearia foi desenvolvido com Java 21, Spring Boot MVC (3.2.5) e banco MariaDB, adotando arquitetura híbrida que combina páginas renderizadas no servidor (Thymeleaf com Layout Dialect para SEO e reuso de fragmentos) com chamadas assíncronas em JSON via JavaScript ES6+ (Fetch API). Na evolução do protótipo, consolidou-se a separação entre a vitrine pública e o painel administrativo, que recebeu refinamento visual, controle de acesso por sessão e perfil (RBAC via interceptadores), rota administrativa ofuscada via arquivo .env, armadilha honeypot retornando HTTP 403 em acessos indevidos e gestão completa de produtos, serviços, clientes, pedidos e agendamentos. Para ampliar a comunicabilidade com o cliente, implementaram-se a página de contato (WhatsApp, telefone e localização), máscaras e validações client-side, agendamento por horários disponíveis em tempo real sem conflitos de agenda e um mini-shopping com mini-carrinho persistido na HttpSession e checkout com Cartão, Pagar na Barbearia e QR Code PIX em SVG calculado localmente com botão de cópia. Por fim, o sistema recebeu o instalador web (/setup) para gravação dinâmica do .env, patches contínuos de correção no carrinho e nos pedidos, páginas amigáveis para erros HTTP 404/500 e cabeçalhos proxy para operação segura em HTTPS atrás de Nginx e Cloudflare.

# Conclusão

O desenvolvimento do sistema web para o Tgo's Barbearia cumpriu o objetivo de unificar agendamentos em tempo real, loja virtual e gestão administrativa em uma plataforma responsiva e segura. A integração entre Java 21 com Spring Boot MVC, persistência relacional via JDBC, Thymeleaf e JavaScript assíncrono consolidou na prática conceitos essenciais de programação web, controle de acesso por perfil e publicação em servidor HTTPS. Como resultado, a solução elimina gargalos manuais no atendimento ao cliente e
estabelece uma base modular pronta para futuras expansões, como integração com gateway real de pagamentos PIX e notificações automáticas.
