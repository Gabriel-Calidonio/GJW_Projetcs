# Fix-002: Erro ao testar conexão com PostgreSQL no Setup Wizard

### Problema
Ao tentar instalar o sistema via Setup Wizard (`/setup`) selecionando **PostgreSQL**, o teste de conexão falha com a mensagem:
`Connection to localhost:5432 refused` ou `password authentication failed`.

Valores que causavam o erro:
- **Host**: `localhost`
- **Porta**: `5432`
- **Banco**: `tgos_db`
- **Usuário**: `admin@admin.com`
- **Senha**: `rootsecret`

---

### Causa Raiz
1. **Host `localhost` dentro do Docker**: A aplicação Java Spring Boot roda dentro do contêiner `tgos_app`. Dentro do contêiner, `localhost` refere-se ao próprio contêiner da aplicação (onde não há banco rodando). Na rede interna do Docker Compose, o contêiner do banco deve ser acessado pelo hostname **`db`** (ou `postgres`).
2. **Confusão de Credenciais**:
   - `admin@admin.com` e `rootsecret` são as credenciais de acesso à interface web do **pgAdmin 4** (porta `5658`) e do **Passo 3** (Administrador Master do sistema).
   - As credenciais padrão do banco de dados relacional definidas no arquivo `.env` são:
     - Usuário: `desenvolvedor`
     - Senha: `**************`

---

### Solução Aplicada
1. Ajustado `docker-compose.postgres.yml` para garantir que `POSTGRES_USER` utilize `${DB_USER}` (`desenvolvedor`).
2. Criada no PostgreSQL a role `"admin@admin.com"` com a senha `"rootsecret"`, permitindo compatibilidade caso o usuário queira usar ambas as credenciais.
3. Atualizado o `README.md` especificando claramente a senha padrão do banco de dados.

---

| Campo | Valor Recomendado | Alternativa Habilitada |
| :--- | :--- | :--- |
| **Servidor (Host)** | `db` *(obrigatório no Docker)* | `postgres` |
| **Porta** | `5432` | `5432` |
| **Nome do Banco** | `tgos_db` | `tgos_db` |
| **Usuário do Banco**| `desenvolvedor` | `admin@admin.com` |
