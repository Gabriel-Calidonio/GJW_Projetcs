# Problemas com Driver MariaDB no Windows e autenticação RSA

### Diagnóstico do Problema

1. **MySQL 8.0+ no Windows vs MariaDB no Linux:**
   - No **Linux**, você costuma ter o **MariaDB** ou MySQL com autenticação padrão legada (`mysql_native_password`), que trafega o hash de senha sem exigir troca de chaves assimétricas.
   - No **Windows**, os pacotes de instalação (MySQL Installer, WampServer ou XAMPP mais recente) instalam o **MySQL 8.0 / 8.4**, cujo plugin de autenticação padrão é o **`caching_sha2_password`**.

2. **Por que ocorre o erro `RSA public key is not available client side`?**
   - Quando o sistema conecta ao MySQL via JDBC em uma conexão local não criptografada (sem SSL/TLS ativo), o MySQL exige que o cliente criptografe a senha utilizando a **chave pública RSA do servidor**.
   - Por questões de segurança (para evitar ataques de interceptação *Man-in-the-Middle*), o driver JDBC (`mariadb-java-client` ou `mysql-connector-j`) **se recusa a baixar automaticamente essa chave pública do servidor** pela rede desprotegida, a menos que o parâmetro `allowPublicKeyRetrieval=true` seja explicitamente autorizado na URL de conexão.
   - Como a URL gerada pelo instalador é `jdbc:mariadb://localhost:3306/nome_banco` (sem parâmetros adicionais), o driver interrompe a conexão e lança essa exceção.

---

### Como Solucionar

Há duas formas de resolver:

#### Opção 1: Ajustar a URL no código da aplicação (Recomendado e Definitivo)
Configurar o instalador ([`SetupService.java`](/src/main/java/com/gwj/service/SetupService.java)) para anexar automaticamente os parâmetros `?allowPublicKeyRetrieval=true&useSSL=false` quando o tipo de banco for MariaDB/MySQL:

```java
String jdbcUrl = "jdbc:mariadb://" + host + ":" + port + "/" + dbName 
               + "?allowPublicKeyRetrieval=true&useSSL=false";
```

Dessa forma, o sistema funcionará perfeitamente tanto em Linux (MariaDB nativo) quanto em Windows com MySQL 8+.

#### Opção 2: Alterar o método de autenticação do usuário no MySQL (No Windows)
Se preferir resolver pontualmente no MySQL do Windows, basta executar no console MySQL:

```sql
ALTER USER 'desenvolvedor'@'localhost' IDENTIFIED WITH mysql_native_password BY 'sua_senha';
FLUSH PRIVILEGES;
```
