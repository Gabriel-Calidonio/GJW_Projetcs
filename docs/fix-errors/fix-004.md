# Fix-001

### O que causou o erro?
O erro `failed to set up container networking: network ... not found` ocorreu porque o contêiner `tgos_db_manager_pg` (pgAdmin 4) já existia no Docker de uma execução anterior e estava vinculado a uma rede antiga que havia sido deletada. Quando o comando `up -d` tentou iniciar esse contêiner pré-existente, o Docker não encontrou a rede antiga registrada nele.

---

### Ações realizadas:

1. **Remoção do contêiner com rede órfã**:
   ```bash
   docker rm tgos_db_manager_pg
   ```
2. **Rebuild e atualização da aplicação com o driver PostgreSQL**:
   Identifiquei também que a imagem antiga de `tgos_app` estava sem o driver JDBC do PostgreSQL no JAR (`No suitable driver found`). Foi executado o rebuild da imagem e a recriação do contêiner:
   ```bash
   docker compose -f docker-compose.yml -f docker-compose.postgres.yml build app
   docker compose -f docker-compose.yml -f docker-compose.postgres.yml up -d --force-recreate app
   ```
