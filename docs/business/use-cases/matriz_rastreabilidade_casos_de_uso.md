## 🏛️ 3. Relação com os Padrões Arquiteturais do Sistema

Esta especificação está 100% ancorada na arquitetura documentada em [`docs/architecture/diagrama.puml`](/docs/architecture/diagrama.puml):

1. **Camada de Apresentação:** Thymeleaf Templates HTML5 + Bootstrap + Vanilla JS com Fetch assíncrono para operações de carrinho e disponibilidade.
2. **Camada de Interceptação:** [`AdminInterceptor`](/src/main/java/com/gwj/controller/AdminInterceptor.java) executando inspeção pré-controlador em todas as rotas de `/MRYnZpAsC9sp/**` para aplicar RBAC dinâmico.
3. **Resolução de Serviços (`ServiceRegistry`):** Os controladores não acoplam diretamente instâncias concretas; invocam `ServiceRegistry.getService(Entidade.class)` para obter a instância gerenciada.
