OBJETIVO DO PROJETO

Aplicar conceitos aprendidos na disciplina de Programação Web.

Integrar conhecimentos de design de interface, programação web e
gerenciamento de projetos.

Trabalhar em equipe para simular um ambiente de desenvolvimento real.

Objetivo

O grupo deverá desenvolver a interface da aplicação utilizando tecnologias modernas de
desenvolvimento web.
Deverão ser considerados os seguintes requisitos:
Utilizar HTML5, CSS3 e JavaScript/TypeScript;
Utilizar obrigatoriamente ao menos um framework ou biblioteca front-end, como:

React;
Angular;
Vue.js;
ou outra tecnologia equivalente previamente aprovada;
Organizar o projeto utilizando componentes reutilizáveis;
Separar adequadamente responsabilidades, estilos, componentes, serviços e demais
recursos da aplicação;
Desenvolver uma interface responsiva e compatível com diferentes tamanhos de tela;
Aplicar boas práticas de usabilidade e experiência do usuário.

WEBSITE (Front-End):

Interface do CRUD:
A interface deverá representar e permitir a utilização das principais operações do CRUD
referente à funcionalidade definida no Projeto Integrador.
Deverão ser implementadas interfaces para:

Cadastro de novos registros;
Consulta e listagem dos registros existentes;
Visualização de um registro específico, quando aplicável;
Atualização de registros;
Exclusão de registros;
Exibição de mensagens de sucesso ou erro após as operações realizadas.

WEBSITE (Front-End):

Integração com o Back-end:

A aplicação front-end deverá estar integrada ao back-end desenvolvido em
Java com Spring Boot, realizando a comunicação por meio de uma API REST.
A integração deverá contemplar:

Consumo dos endpoints disponibilizados pela API REST;
Realização de requisições utilizando os métodos HTTP adequados:
GET para consultas;
POST para criação de registros;
PUT ou PATCH para atualização;
DELETE para exclusão;
WEBSITE (Front-End):

Integração com o Back-end:

Envio e recebimento de dados no formato JSON;
Exibição dos dados retornados pelo back-end na interface;
Envio dos dados dos formulários para a API;
Tratamento das respostas retornadas pela API;
Tratamento de erros de comunicação com o back-end;
Exibição de mensagens adequadas ao usuário em situações de sucesso ou erro;
Utilização da autenticação fornecida pelo back-end, quando aplicável;
Proteção das páginas ou funcionalidades que necessitem de usuário
autenticado.
A aplicação front-end não deverá utilizar dados fixos ou simulados como
solução final. As informações apresentadas deverão ser obtidas por meio da API
desenvolvida pelo grupo.
WEBSITE (Front-End):

Validações e Tratamento da Interface

Validar os dados antes do envio ao back-end;
Indicar campos obrigatórios;
Exibir mensagens de validação de forma clara;
Impedir o envio de formulários com dados inválidos;
Tratar mensagens de erro retornadas pela API;
Informar visualmente quando uma operação for concluída com sucesso;
Apresentar indicador de carregamento quando houver comunicação com a API.

WEBSITE (Front-End):

Trabalho Colaborativo e Versionamento

Utilizar Git para versionamento do projeto;
Manter o código em um repositório remoto, preferencialmente no
GitHub;
Garantir a participação de todos os integrantes no desenvolvimento;
Realizar commits individuais e frequentes;
Utilizar mensagens de commit claras e relacionadas às atividades
realizadas;
Utilizar branches para desenvolvimento de funcionalidades, quando
aplicável;
Realizar integração das alterações realizadas pelos integrantes;

WEBSITE (Front-End):

Deploy:

Deploy do front-end desenvolvido;
Disponibilização de uma URL pública para acesso à aplicação;
Configuração adequada da aplicação para consumir a API REST
publicada;
Integração entre o front-end publicado e o back-end publicado;
Testes após o deploy para garantir o funcionamento das operações;
Verificação do funcionamento do CRUD no ambiente publicado;

WEBSITE (Front-End):

Link do repositório GitHub;
Histórico de commits dos integrantes;
Link do deploy do front-end;
Link do deploy do back-end/API;
Readme sobre o explicativo do projeto
